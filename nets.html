Simple Printable Net Builder

Pick one tool, click the net, drag blue corner dots anytime, and move copied nets independently. Tabs now angle only the end that needs clearance.

1 Make the base

A regular polygon base uses the width box as the edge length. The base will only change when you drag its own blue corners or set one of its side lengths.

2 Build and edit

Blue dots are always draggable. Drag a corner dot to change a shape. Click a side with the selected tool below.

Click a side to set and lock its length. Nothing gets added in this mode.

3 Make it fit

Auto-grow stops the net being trapped on A4. You can also type any page size you want.

4 Download / print

Use the PDF for laser/craft cutters: RGB red cut lines and RGB blue fold lines.

Quick help

Select / set length: safely click a side before typing its size.

Add sides: choose rectangle, triangle, or polygon, then click an outside edge.

Pair matching sides: type a number, then click the two sides that should match. Change the number yourself for a new pair.

Move corners: drag blue corner dots. Joined edges stay attached.

Shortcuts: Ctrl+Z undo, Ctrl+Y or Ctrl+Shift+Z redo, Ctrl+C copy, Ctrl+V paste, Delete remove.

Tabs: click outside edges. Tabs cannot go between two joined shapes. If a tab is close to another shape, only the clashing end angles in first.
